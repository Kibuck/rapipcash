# Catatan Kas (tanpa API)
1. Buka index.html di browser untuk tes baca gambar.
2. Spreadsheet > Extensions > Apps Script > tempel isi Code.gs, ganti TOKEN, lalu Deploy > New deployment > Web app (Execute as: Me, Access: Anyone). Salin URL-nya.
3. Di halaman, buka Pengaturan, isi URL dan kode rahasia yang sama.
4. Agar bisa dibuka dari HP, taruh folder ini di hosting statis (misalnya Vercel).
